# 多鄰國（Duolingo）風格研究

這份文件整理多鄰國（Duolingo）在視覺設計、遊戲化機制、學習流程、文案語氣、動效音效等面向的風格特色，作為本專案（Duolingo_try）未來設計與開發的參考依據。

## 1. 品牌與視覺設計

- **主色調**：品牌綠 `#58CC02`（Duo 綠）是最核心的識別色，代表正向、成長、正確。
- **輔助色系**：依情境切換高飽和顏色——
  - 藍色（`#1CB0F6`）：一般資訊、連結、次要按鈕
  - 紅色（`#FF4B4B`）：錯誤、扣血、警示
  - 黃色（`#FFC800`）：金幣/獎勵、提示
  - 紫色（`#CE82FF`）：進階內容、特殊活動
- **配色邏輯**：對比強烈、飽和度高，情緒與功能直接掛鉤色彩（答對=綠、答錯=紅），使用者不需閱讀文字就能理解狀態。
- **字體**：圓潤、粗體、字級偏大，強調高辨識度與親和力（例如 Duolingo 自製字體 Feather），標題常用全大寫或加粗處理。
- **吉祥物與角色插畫**：
  - 主角貓頭鷹 Duo：扁平化、圓潤造型、大眼睛、誇張表情，個性鮮明（甚至帶點「陰森幽默」的反差萌）。
  - 其他角色（Lily、Zari、Falstaff 等）各有性格設定，用於不同情境的引導與陪伴。
  - 插畫整體走扁平向量風格，色塊分明、無複雜漸層。
- **版面元素**：
  - 大量圓角（卡片、按鈕、對話框無銳角）。
  - 卡片式版面（Card UI）承載課程、商店項目、成就等內容區塊。
  - 按鈕具備「立體按壓感」：底部有一層較深色的「厚度」陰影，點擊時按鈕視覺下沉，模擬實體按鍵回饋。
- **圖示風格**：簡單、卡通化、色塊分明，避免寫實或線條過細的圖示，確保在小尺寸下依然清晰。

## 2. 遊戲化機制（Gamification）

- **連續學習天數（Streak）**：以火焰圖示呈現，是多鄰國最核心的黏著機制之一；使用者害怕「斷開連續紀錄」，因而養成每日打開 App 的習慣。搭配「連續紀錄凍結（Streak Freeze）」等道具，讓玩家花費虛擬貨幣保護紀錄。
- **經驗值（XP）與每日目標**：每次練習獲得 XP，使用者可自訂每日 XP 目標，達標後有慶祝回饋。
- **等級與聯賽排行榜（Leagues）**：每週依 XP 分組競賽，聯賽分級（青銅、白銀、黃金…至鑽石），前段名次可升級，末段則降級，製造持續回訪動機。
- **生命值/心（Hearts）機制**：練習中答錯會扣血，血量歸零則無法繼續練習，需等待恢復、看廣告、花寶石或訂閱付費版解鎖無限生命——同時是遊戲張力來源，也是付費轉換的關鍵設計。
- **虛擬經濟系統**：寶石（Gems）作為虛擬貨幣，可在商店購買生命值恢復、連續紀錄凍結、頭像裝飾等，建立完整的內部經濟循環。
- **成就徽章與慶祝動畫**：完成里程碑（如完成單元、達成連續天數）會觸發五彩紙屑動畫、徽章頒發與正向音效，強化成就感。

## 3. 學習流程與課程設計

- **技能樹/關卡地圖**：課程以蜿蜒道路（Path）視覺化呈現，每個節點代表一個關卡，使用者沿路徑推進，直觀看見自己的學習進度與後續內容。
- **小顆粒練習設計**：每個關卡拆解成多種短小題型（選擇題、填空、拼字、聽力辨識、口說跟讀、配對連連看等），單次練習通常控制在 3-5 分鐘內，降低學習門檻與時間壓力。
- **間隔複習（Spaced Repetition）**：系統依據遺忘曲線提醒使用者複習已學過但可能生疏的內容，強化長期記憶。
- **即時回饋**：每題作答後立即給予視覺（打勾/打叉、顏色變化）與聽覺（音效）回饋，並在答錯時提供正確答案與簡短解說，語氣偏向鼓勵而非懲罰。

## 4. 語氣與文案風格

- **俏皮、幽默的品牌人格**：文案常帶有輕鬆、自嘲或誇張的幽默感，塑造出「有個性」的品牌形象。
- **知名的「情緒勒索」推播提醒**：Duo 貓頭鷹會在使用者未完成每日練習時發出帶點威脅／賣萌的提醒通知（例如暗示「Duo 很傷心」），是被廣泛討論、模仿的行銷特色，也常被做成迷因。
- **鼓勵導向的用語**：即使答錯，文案也會以正向語句降低挫折感（例如強調「幾乎就對了！」），並在完成小目標時給予明確稱讚與慶祝文字。
- **角色化對話**：不同角色在課程情境或動畫中會有各自的口吻與吐槽，增加陪伴感與趣味性。

## 5. 動效與音效

- **微互動動畫**：按鈕按下的彈跳效果、角色表情隨結果切換、進度條/血條的填充動畫等，讓介面感覺「有生命」。
- **正向音效回饋**：答對時清脆上揚的音效、升級或完成關卡時的慶祝音效，強化操作的即時滿足感；答錯音效則短促但不刺耳，避免過度負面。
- **轉場與慶祝效果**：完成單元、升級聯賽、達成連續天數里程碑時，常搭配全螢幕慶祝動畫（五彩紙屑、放大縮小的角色插畫）。

## 若要在本專案中套用：具體建議清單

### 視覺 / 色票
- 主色：`#58CC02`（正確／主要操作）
- 錯誤色：`#FF4B4B`
- 資訊／連結色：`#1CB0F6`
- 獎勵／金幣色：`#FFC800`
- 背景：淺灰或白（`#FFFFFF` / `#F7F7F7`），避免使用深色背景干擾高飽和主色
- 圓角統一使用較大的 `border-radius`（例如 12-16px），按鈕採用「底部厚度陰影 + 點擊下沉」效果

### 需要的核心 UI 元件
- 關卡地圖（Path/Skill Tree）組件：蜿蜒路徑 + 節點狀態（未解鎖/可練習/已完成）
- 頂部狀態列：連續天數（🔥 streak）、生命值（❤️ hearts）、寶石（💎 gems）、XP 顯示
- 練習題型組件：選擇題、拼字輸入、聽力題、配對題（可視專案範圍先做 1-2 種 MVP）
- 即時回饋 Modal：答對/答錯的全螢幕或半螢幕提示框，附音效與動畫
- 慶祝畫面：完成關卡/單元後的五彩紙屑 + 角色動畫 + XP 結算
- 每日目標與進度條組件
- 排行榜/聯賽列表組件（可作為後期功能）

### 文案語氣建議
- 錯誤提示避免生硬（如「錯誤」），改用鼓勵語句（如「差一點點！正確答案是…」）
- 完成里程碑時使用簡短、有活力的稱讚語句
- 可設計一個吉祥物角色，在關鍵時刻（開始練習、完成、犯錯）給予帶個性的回饋文字

### MVP 優先順序建議
1. 先做出關卡地圖 + 一種練習題型（如選擇題）+ 即時對錯回饋
2. 加入 XP 與每日目標
3. 加入連續天數（streak）機制
4. 加入生命值機制與慶祝動畫
5. 進階：聯賽排行榜、虛擬商店、間隔複習
